# 标准模型互动实验室 V16.1 — 导航组间距修订

基于 V16，**只更改导航 HTML 结构**；任何科学文案、动画、样式表和脚本均未修改。

导航从三组恢复为四组：
1. 标准模型／粒子结构／粒子质量
2. 四种力／强力／弱力／电磁力／引力
3. 诺特定理／规范场／对称性破缺／时空观
4. 怎么知道／理论边界

在时空观之后增加与引力和诺特定理之间完全相同的 `.nav-divider`；新组保留 `nav-group-info`，因此默认、悬停和选中颜色与其他信息域页签一致。

下载方式：可直接打开 `Standard_Model_V16_1.html`；如需部署，从 ZIP 解压 `standard-model` 文件夹，将其中文件放在同一目录运行。
